Sobre o Projeto

O que é a HandPulse?

A HandPulse é uma luva inteligente desenvolvida para o monitoramento de tremores e movimentos involuntários das mãos. Através de sensores de movimento, a luva consegue identificar como a mão está se movimentando e transformar essas informações em dados que podem ser analisados pelo sistema. A proposta combina eletrônica, programação, coleta de dados e Inteligência Artificial para desenvolver uma tecnologia capaz de acompanhar os movimentos em tempo real e, futuramente, oferecer respostas cada vez mais personalizadas.

Como funciona?

A HandPulse utiliza um sensor chamado MPU6050, que funciona como um pequeno sistema capaz de perceber os movimentos e mudanças na posição da mão.

Ele registra informações sobre diferentes direções do movimento, permitindo que o sistema identifique características dos tremores. Essas informações são processadas por um ESP32, um pequeno computador utilizado na luva. Ele recebe os dados do sensor, realiza os cálculos necessários e envia as informações para o sistema.

Quando determinadas características de tremor são identificadas, um motor Vibracall pode ser acionado. Esse motor produz uma pequena vibração na luva, funcionando como uma forma de estimulação vibratória e resposta ao movimento detectado.

De forma simplificada: o sensor percebe o movimento, o ESP32 processa as informações e a luva pode responder através da vibração.

Dados e Inteligência Artificial

Além de responder aos movimentos, a HandPulse também realiza a coleta e o armazenamento dos dados. As informações podem ser enviadas para o Firebase, um serviço utilizado para armazenar os dados coletados pela luva.

Esses dados também podem ser apresentados em um dashboard, uma interface visual que permite acompanhar as informações de maneira mais fácil, como os níveis de movimento, intensidade e ocorrência de tremores.

A coleta desses dados é importante para uma das próximas etapas do projeto: o uso de Inteligência Artificial. A ideia é que, com uma quantidade suficiente de informações, a IA possa ajudar a identificar padrões nos tremores e compreender melhor as características dos movimentos de cada usuário.

Qual o nosso objetivo?

O objetivo da HandPulse é desenvolver uma tecnologia vestível capaz de monitorar tremores, coletar informações sobre os movimentos e utilizar esses dados para pesquisas e futuras aplicações de Inteligência Artificial.

A longo prazo, buscamos tornar o sistema capaz de reconhecer diferentes padrões de movimento e contribuir para uma estimulação vibratória mais personalizada.

A HandPulse ainda está em fase de desenvolvimento e pesquisa. Por isso, seus resultados e possibilidades estão sendo avaliados através de testes e da análise dos dados coletados.

Tecnologias Utilizadas

  • ESP32 Microcontrolador responsável pelo processamento e comunicação dos dados.
  • MPU6050 Sensor utilizado para detectar os movimentos da mão.
  • Motor Vibracall Responsável pela estimulação vibratória da luva.
  • Firebase Utilizado para armazenar os dados coletados.
  • Angular Utilizado para desenvolver a interface do sistema.
  • TypeScript Utilizado no desenvolvimento da aplicação.
  • Inteligência Artificial Parte da proposta para análise dos dados e identificação de padrões.
