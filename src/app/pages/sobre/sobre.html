Sobre o Projeto

HandPulse

O que é o HandPulse?

O HandPulse é uma luva inteligente desenvolvida para monitorar movimentos involuntários das mãos utilizando sensores de movimento e um sistema de vibração tátil.

Objetivo

Auxiliar pessoas que possuem tremores ou dificuldades motoras, fornecendo monitoramento em tempo real e coleta de dados para futuras análises com Inteligência Artificial.

Tecnologias Utilizadas

  • ESP32
  • MPU6050
  • Motor Vibracall
  • Firebase
  • Angular
  • TypeScript

Equipe

Projeto desenvolvido para a FETIN 2026.
